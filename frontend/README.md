# Society Management System - Frontend

This is the frontend application for the Society Management System built with Angular.

## Features

- Admin dashboard for flat owner management
- Flat owner portal for family member and tenant management
- Maintenance payment and receipt generation
- Visitor management with approval workflow

## Technologies

- Angular 16
- TypeScript
- RxJS
- HttpClient

## Development Server

Run `npm install` to install dependencies.

Run `npm start` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

## Build

Run `npm run build` to build the project. The build artifacts will be stored in the `dist/` directory.

## Running Tests

Run `npm test` to execute the unit tests via Karma.
